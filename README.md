# Домашняя работа 10.2
Продолжаем работу над проектом. Тестирование своего кода - важная часть разработки. Тестирование позволяет не только - 
убедиться, что в коде нет ошибок, но и продумать архитектуру своего решения.
## Установка
[Проект можно клонировать с GitHub](https://github.com/Sergey-Shinkevich/Bank_app) 
## Зависимости
+ Python 3.14
+ Black 26.1.0
+ Flake8 7.3.0
+ Isort 7.0.0
+ Mypy 1.19.1
+ Pytest 9.0.2
+ Pytest-cov 7.0.0
## Задачи
1. Используйте библиотеку *pytest* и напишите тесты для существующего кода проекта. 
2. Примените фикстуры для создания необходимых входных данных для тестов.
3. Используйте параметризацию в тестах для обеспечения тестирования функциональности 
с различными входными данными, избегайте дублирования кода.
4. Добейтесь покрытия тестами не менее 80% кода.
